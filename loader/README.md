# Desktop application

Run from the repository root with `./run.sh`, or use `Start-Mod-Loader.cmd` on Windows. Python 3.11+ and host PySide6 6.x are required. No dependencies are downloaded by the launcher.

Use `--no-launch --data local/review` for an isolated review. The handpicked bundle seeds Squishy Plushie, Futuristic Courier, Power Poles, F4 Debug Menu and their five dependencies, initially unchecked. Existing versions and checkmarks are preserved. Import other local `.msmod` archives with **Install mod package**. The root README describes the native build, private game-copy/profile policy and qualification limits.
