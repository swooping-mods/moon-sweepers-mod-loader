# Desktop application

Run from the repository root with `./run.sh`, or use `Start-Mod-Loader.cmd` on Windows. Python 3.11+ and host PySide6 6.x are required. No dependencies are downloaded by the launcher.

Use `--no-launch --data local/review` for an isolated review. Import local `.msmod` archives into the initially empty library. The root README describes the native build, private game-copy/profile policy and qualification limits.
